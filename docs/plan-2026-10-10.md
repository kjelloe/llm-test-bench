### Review of this plan (2026-10-12)
- **Fixture independence:** F1's fixtures come from three itself, not from the reference, so the reference is
  tested against the real thing. F2's ground truth would otherwise be the reference code; cross-check a few
  widths with an independent Python reader before trusting it. F4 needs values from the CSS spec, not from
  the reference (hsl rounding, percentage rounding are where parsers differ).
- **Leakage:** the bundled fonts and three's output are public; the risk is a model that has memorised
  three's geometry code — fine, that is the skill being tested (porting faithfully).
- **Difficulty spread:** F1-F4 are L2-L4 code; F5 adds reasoning items. The gamedev diag set was too easy at
  the top, so the fastengine questions should use the "known tempting wrong answer" each incident names as a
  distractor and keep option lengths balanced.
- **Cost:** each C# task builds in seconds on net9.0; F3 starts Node per test (~1-2 s each). Model runs ~1 h
  single GPU for four models, ~1 h for the two 3×24 GB models with the clock lock.
- **Risk:** F3 timing on a loaded machine — use generous timeouts and assert ordering, not durations; F2's
  format 12 may not occur in the bundled fonts — check, and if absent, test format 12 on a small synthetic
  table built in the test.
