OBSERVABILITY PLATFORM — Configuration Reference v4.7

Inheritance rule: a profile's effective value for any key is the first definition
of that key found by walking from the profile to its parent, then the parent's
parent, and so on, stopping at the first ancestor that defines the key.
A profile with no parent field is the root.
